Описание проекта

Консольное Kotlin-приложение "Симуляция острова" для моделирования экосистемы с хищниками, травоядными и растениями. Система позволяет наблюдать за процессами перемещения, питания, размножения и гибели животных в реальном времени с пошаговой визуализацией состояния острова.
Структура проекта
Основные пакеты и классы:

IslandMain.Simulation - пакет с логикой симуляции:
Island.kt - Класс острова с сеткой локаций
Simulation.kt - Класс управления тактами симуляции
IslandMain.entities - пакет с сущностями:
Animal.kt - Абстрактный класс животного
Predator.kt - Класс хищника
Herbivore.kt - Класс травоядного
Location.kt - Класс локации (клетки острова)
Wolf.kt, Bear.kt, Fox.kt, Snake.kt, Eagle.kt - Классы хищников

Deer.kt, Rabbit.kt, Goat.kt, Horse.kt, Boar.kt, Mouse.kt, Buffalo.kt, Sheep.kt, Caterpillar.kt - Классы травоядных
IslandMain - корневой пакет:
Config.kt - Класс конфигурации параметров симуляции
Main.kt - Точка входа в приложение

Технологии
Язык программирования:	Kotlin
Платформа:	JVM (Java Virtual Machine)
Среда разработки:	IntelliJ IDEA
Система сборки:	Java модуль (IntelliJ)
Многопоточность:	ScheduledThreadPoolExecutor (java.util.concurrent)
Генерация случайных чисел:	kotlin.random.Random

Симуляция острова — это консольное приложение на Kotlin, которое моделирует экосистему с 14 видами животных (хищниками и травоядными), автоматически управляя их перемещением по клеткам острова, питанием (охота или поедание растений), размножением при наличии пары и гибелью от голода, отображая состояние карты после каждого такта длительностью 2 секунды.
